# Culture Here — 서울 MVP

서울 지역 문화·교육·체험 프로그램 탐색 서비스의 초기 UI 프로토타입.

## 현재 포함
- 반응형 랜딩/검색 화면
- 키워드 검색
- 카테고리, 대상, 비용, 자치구 필터
- 예시 프로그램 카드 및 상세 모달
- 25개 서울 자치구 선택
- 빈 결과 상태 및 필터 초기화
- 모든 데이터는 테스트용 샘플임을 UI에서 명시

## 아직 미포함
- 실제 공공 API 연동
- 서버/DB
- 사용자 로그인/즐겨찾기
- 일정 알림
- 실제 모집 상태 확인

## 로컬 확인
index.html을 브라우저에서 열면 됩니다.

## GitHub Pages
Repository Settings → Pages → Build and deployment → Deploy from a branch → main / root 선택 후 저장.
