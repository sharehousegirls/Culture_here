# Culture Here — 전국 문화·교육·체험 프로그램 탐색 서비스

전국의 문화·교육·체험 프로그램을 통합 검색하고 지역과 관심사에 맞게 발견할 수 있도록 돕는 웹서비스. 서울은 초기 테스트 지역일 뿐, 서비스와 데이터 구조는 전국 확장을 목표로 설계한다.

## 현재 포함
- 반응형 랜딩/검색 화면
- 키워드 검색
- 카테고리, 대상, 비용, 지역 필터 UI
- 예시 프로그램 카드 및 상세 모달
- 빈 결과 상태 및 필터 초기화
- 모든 데이터는 테스트용 샘플임을 UI에서 명시
- GitHub Pages 배포 workflow 및 CI 검증 workflow

## 개발 로드맵
1. **전국형 브랜딩 및 공개 MVP** — 완료
2. **GitHub Pages 배포** — 완료, 실제 접속 확인
3. **지역 분류 체계 및 데이터 모델** — 전국 시·도/시·군·구와 데이터 출처·수집 시각·원본 ID를 유지하는 구조로 설계
4. **실제 API 연동** — 확보한 API부터 응답과 사용 조건을 검증하고 안전하게 연결
5. **API 자동 발굴 파이프라인** — 공공데이터포털·중앙부처·지자체·공공기관·도서관·문화시설·교육기관의 신규 프로그램 API를 주기적으로 탐색, 기존 목록과 중복 비교, 후보 평가, 신청 필요 여부 분류, 신청서 초안 준비
6. **데이터 정규화 및 중복 제거** — 출처별 수집, 공통 필드 매핑, 중복 판정, 데이터 품질/최신성 관리
7. **지역별 단계적 데이터 확대** — 실제 확보된 데이터 지역만 표시하고, 데이터 미확보와 프로그램 없음을 구분
8. **검색/사용성 개선 및 수요 검증** — 실사용 검색 품질, 프로그램 상세, 출처 링크 검증
9. **운영/수익화 검토** — 사용량과 수요 확인 이후 광고·제휴 등 저비용 수익 모델 검토

## API 자동 발굴 기준
- 프로그램 정보(문화, 교육, 강좌, 행사, 공연, 전시, 체험, 모집/신청) 제공 여부를 우선
- 전국 또는 지역 범위, 제공 필드(일정, 신청기간, 대상, 비용, 장소, 모집상태), 갱신주기, API 방식, 인증/신청 조건, 이용 약관, 연동 난이도 기록
- 기존 API와 중복되지 않는 후보만 추가 검토
- 신규 후보가 발견되면 공식 출처, 데이터 범위, 적합성, 우선순위, 신청 절차 및 활용 목적 문구를 정리
- 최종 제출, 본인 인증, 계정 권한이 필요한 단계는 사용자 확인 필요
- API 키와 비밀값은 공개 코드에 저장하지 않으며 환경변수/비밀 저장소로 관리

## 현재 API 현황 (작업 기록)
- 문화포털 문화정보 조회서비스: 전국 범위 후보, 신청/승인 대기 상태를 확인하며 진행
- 전국 평생학습강좌 표준데이터: 미신청
- 문체부 소속 및 산하기관 교육정보 API: 대구로 관리, 인증키 발급됨
- 국립박물관 문화행사 통합정보 API: 미신청
- 국립어린이청소년도서관 공개모집 API: 대구로 관리, 인증키 발급됨

※ 지역 분류는 현재 사용자 지정 운영 범위이며, 실제 응답 데이터의 지리적 범위는 연동 시 검증한다. 실제 API 키는 README나 저장소에 기록하지 않는다.

## 보안
- API 키, 비밀번호, 개인정보, `.env` 파일을 Git에 커밋하지 않는다.
- 브라우저에 노출되는 API 키는 비밀이 아니다. 민감한 키는 백엔드 또는 GitHub Actions Secrets 등 안전한 환경에서 관리한다.
- 공개 저장소에 올리기 전 secrets와 로그를 검토한다.
